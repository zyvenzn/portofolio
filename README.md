# ZyvenGM — Digital Portfolio

A clean, responsive personal portfolio built with **React**, **TypeScript**, **Vite**, and **Framer Motion**.

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Stack

- React + TypeScript
- Vite
- Framer Motion
- Lucide React
- Custom responsive CSS
